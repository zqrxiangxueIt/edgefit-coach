# 实拍演示视频拍摄脚本（M4-5）

目标：3-4 分钟讲清「两设备协同 + 四模式价值 + 真实计数」，画面里同时出现系统与真人。

## 开拍前检查清单

- [ ] 摄像头机位：**侧面 45°~90°**，距离让你占画面高度 1/2 以上（半身）
- [ ] Pi 5 与摄像头入镜（拍到设备本体，体现"边缘设备"）
- [ ] 电脑屏幕（仪表盘）入镜——手机/相机拍屏幕不闪屏的话优先实拍；也可后期录屏画中画
- [ ] 哑铃就位
- [ ] 系统启动：
  ```bash
  # Pi（经 ssh）
  cd ~/edgefit && .venv/bin/python -u -m edge.edge_main --mode raw --source camera --bind tcp://0.0.0.0:5555 --keepalive 30
  # PC
  .venv\Scripts\python server\app.py     # 打开 http://127.0.0.1:8000
  ```

## 分镜（建议顺序）

| # | 时长 | 画面/动作 | 要讲/展示的点 |
|---|---|---|---|
| 1 | 20s | 设备全家福：Pi+摄像头 → 屏幕 | "树莓派做初步计算，PC 跑神经网络" |
| 2 | 15s | 点 `raw` 模式，人走出画面 | 带宽曲线 ~1180KB/s 持续跳动——没人也在传 |
| 3 | 15s | 点 `event`，静止 3 秒 | 曲线掉到 ~30KB/s；做动作立刻恢复 |
| 4 | 20s | 点 `cascade`，走远/出画 | 无人→静默（1fps 心跳）；人回画面→瞬间恢复 30fps——"端侧神经网络在决定发不发" |
| 5 | 20s | 点 `privacy`，出画再入画 | 无人→黑帧（0.7KB/s）；入画→只见你的人形 ROI，背景永不传输 |
| 6 | 60s | **核心秀**：侧面坐好，连续 10 个标准弯举 | 计数跳动、extended/curling 相位切换、角度 HUD；故意做 2 个半程 → "幅度不足"警告；甩躯干 → "躯干摆动"警告 |
| 7 | 20s | 收尾：摊开手臂 + 屏幕定格 | 一句话总结："边缘初步计算 + 边缘神经网络 = 低带宽、隐私友好、实时的 AI 教练" |

## 拍摄技巧

- 手机横屏 1080p/4K，固定机位同时拍到 屏幕+人+Pi 设备（L 形布局）
- 模式切换时**鼠标动作放慢**，切完停 2 秒让观众看曲线变化
- 计数环节语速放慢，每次报数后自然停顿
