# 实拍演示视频拍摄脚本 v2（总长目标 3:05，硬上限 3:30）

调研依据：评审在前 30-45 秒形成印象；问题开场优于设备巡礼；最记住"真实工作品 + 故意失败被抓 + 可核验数字"；关键数字要大字上屏（小屏静音观看假设）。详细策略见 [prototype_demo_video_strategy.md](prototype_demo_video_strategy.md)。

## 开拍前检查清单

- [ ] **先拍分镜⑥**（返工率最高）
- [ ] 录屏方案：**OBS 60fps 录屏 + 画中画**（手机翻拍屏幕是备选：快门锁 1/60、屏幕最亮、侧倾 5-10° 防摩尔纹，先拍 10s 试片）
- [ ] 主机位：手机横屏，**同时拍到 屏幕 + 你 + Pi 设备**（L 形布局），AE/AF/AWB 三锁
- [ ] 机位：**侧面 45-90°**，人占画面 ≥1/2；逆光是大敌（侧光），彩排时验证 event 模式静默达成
- [ ] 系统：`start_system.bat` → 网页点 ⏻；确认仪表盘"🔊 语音"亮着（视频里系统要开口）
- [ ] 清场（多人会触发"多人画面"警告）
- [ ] 预热数据：提前做 1-2 次训练让"历史图表/超越上次"有内容可显示

## 分镜 v2

| # | 时长 | 画面/动作 | 台词/字幕要点 |
|---|---|---|---|
| ① | 15s | **问题开场**：raw 模式下人走出画面，带宽曲线仍 ~1180KB/s（大字上屏）| "一台没人看的摄像头，也在传每秒 1.2MB" |
| ② | 20s | 点 `event`：静止时曲线掉到 ~2KB/s；动一下立刻恢复 | 字幕卡：**-98%**（大字）|
| ③ | 20s | 点 `cascade`：出画→完全静默；入画→瞬间恢复 | "这次决定发不发的，是树莓派上的神经网络"（画面切 Pi）|
| ④ | 20s | 点 `privacy`：黑帧 → 入画只见人形 ROI | "镜头看到了房间，但上传的只有你" |
| ⑤ | 10s | 点"▶ 开始训练"：**3-2-1 倒计时**转场（语音播报）| — |
| ⑥ | 70s | **核心秀**：侧面标准弯举；系统**语音报数**；ROM 表盘指针进绿区；逐次柱图堆起来。然后**故意三连错**：2 个半程（警告+柱图变琥珀色+表盘不进绿区）→ 1 次快速下放（"下放过快"）→ 1 次甩躯干（"躯干摆动"）。若有半身出画瞬间，展示"幽灵计数拦截"数字 | 不需要台词，让系统的声音和警告横幅自己说话 |
| ⑦ | 15s | **Results**：完成评分卡（全程率%）+ 历史图表 + "超越上次"横幅 + 延迟 HUD | "每次训练都有记录——B 端是系统的记忆" |
| ⑧ | 15s | 点 ⏻ 关停 → 带宽归零、摄像头释放 | "不用的时候，一个字节都不传" |

**超时删减顺序**（不删：⑥错误三连、幽灵拦截、⑦数据卡）：删④→③→②各压到 12s。

## 与 v1 的差异

- 砍掉设备全家福（硬件并入③④背景），改为问题开场
- 新增：TTS 语音报数/警告、节奏桥段（快放）、ROM 表盘+柱图的视觉叙事、完成评分卡、超越上次横幅
- 分镜⑥从"60s 自由发挥"细化为"标准→三连错→拦截"的可排练剧本
